# Main Model Result Snapshot

This directory contains the result set generated by the primary 24-hour `case1354_multiperiod_market` run:

- `case1354_multiperiod_sced.xlsx`: readable dispatch, price, security, and audit tables.
- `case1354_multiperiod_sced.mat`: MATLAB result structure for further analysis.
- `*_config.json`, `*_manifest.json`, and `*_runlog.csv`: run configuration and traceability artifacts.

These files are a shared example snapshot. New local runs should normally write to a different result folder and should not be committed automatically.
